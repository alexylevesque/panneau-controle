Faire sonner : configurationUne seule fois
  1. Sur l'iPhone, installe l'appli Pushover et crée un compte (essai gratuit, puis environ 7 $ une fois).
  2. Dans l'appli Pushover, copie ta User Key.
  3. Sur pushover.net > Create an Application, nomme-la Panneau et copie l'API Token.
  4. Dans Pushover sur l'iPhone : Settings > active Critical Alerts (pour sonner même en silencieux).

Connecter ton iPhone
1. Pile — appli Raccourcis sur l'iPhone
  1. Raccourcis > +, nomme-le Panneau. Ajoute Obtenir le niveau de la batterie.
  2. Ajoute Obtenir le contenu de l'URL : …
  3. Touche la flèche : Méthode POST, Corps JSON : id = iphone · nom = iPhone · batterie = Niveau de la batterie
  4. Onglet Automatisation : lance-le quand le chargeur est branché/débranché et quand tu rejoins ton Wi-Fi (« Exécuter immédiatement »).
2. Notifications et appels — appli Pont iPhone sur la tablette
  1. Dans Chrome sur la tablette, télécharge et installe :
    github.com/alexylevesque/panneau-controle/releases/download/pont/pont-iphone.apk
  2. Ouvre Pont iPhone. Sur l'iPhone, avec l'appli gratuite nRF Connect : SCAN, puis CONNECT sur Panneau.
  3. Accepte le jumelage et Autoriser les notifications sur l'iPhone.
